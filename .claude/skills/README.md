# Fiches de méthode (skills) de Veille Santé

Copie des skills communs aux applications de l'écosystème (décision de coordination POR-D24,
consigne CONS-2026-11-12-01, appliquée avec l'accord du porteur du projet : VS-D35).

**La référence est le dossier `.claude/skills/` du dépôt de coordination `MK-master974/ecosysteme`.**
Copie faite le 12 novembre 2026, à partir de son commit `0ecdc22`.

| Skill | Sert à |
|---|---|
| `message-cons07` | Écrire un message au porteur du projet ou au portail |
| `questionnaire-decision` | Poser une décision au porteur du projet |
| `declaration-portail` | Déclarer au portail une évolution qui touche une autre application |
| `aucune-donnee-patient` | Contrôler l'absence de données de patients et de secrets avant un envoi |
| `verifier-avant-terminer` | Vérifier avant d'annoncer « terminé » |
| `debogage-methodique` | Chercher la cause d'un défaut avant de le corriger |
| `publication-version` | Publier une version |

**Règles de copie :**

- le texte d'un skill n'est adapté que dans sa partie « Dans ce projet » ;
- tout autre changement se fait d'abord dans le dépôt de coordination, pour que les copies restent
  semblables ;
- les règles impératives de Veille Santé restent dans [`CLAUDE.md`](../../CLAUDE.md), qui est lu en
  entier par chaque session : un skill n'est lu que lorsqu'il sert.
